Collect any important notes that should be included in the top of the release notes.
If there are no important notes, simply skip this step.

Here is the template, empty sections must be removed:

```
### 🚨 BREAKING CHANGES 🚨

...

### 📢 IMPORTANT 📢

...

### ⚠️ DEPRECATIONS ⚠️

...
```

Output the collected important notes to `tmp/important-notes.md` for further processing.
