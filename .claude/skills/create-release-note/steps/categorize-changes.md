Organize the changes into categories.
It's allowed to assign multiple categories to a single change.

Categories include:
- ✨ New Features
- 💡 Behavior Changes
- 🗑️ Removals
- 🚀 Performances
- 🐛 Bugfixes
- 📄 Docs
  - Examples should be included here
- 💯 Tests
- 💻 Refactors
- 🧹 Chores
- 📦 Deps

Put the emoji at the beginning of each line in `tmp/commit-history.txt`.

```
✨ abcd123 Added ...
🐛 abcd123 Fixed ...
✨ abcd123 Added ...
💡🐛 abcd123 Changed ... This also fixes ...
📄 abcd123 Updated docs for ...
📦 abcd123 Bump ...
```
